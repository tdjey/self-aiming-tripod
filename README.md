# Self-aiming tripod

Штатив для записи лекций, который сам поворачивается за лектором. Mac получает видео с iPhone
через Continuity Camera, YOLO находит людей в кадре, трекер держит лектора, а контроллер решает,
когда повернуть камеру. Команды уходят по USB на Arduino Nano, которая крутит серву

## Запуск

```bash
python3.11 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python -m tools.list_cameras
.venv/bin/python -m tripod.main --port /dev/cu.usbserial-10
```

Веса YOLO скачаются сами при первом запуске. Без `--port` программа работает без Arduino и
только показывает на экране, куда надо повернуть

При первом запуске macOS спросит доступ к камере для терминала, нужно разрешить и запустить ещё
раз. В Пункте управления -> "Видеоэффекты" лучше выключить Center Stage, иначе iPhone будет
кадрировать сам.

Флаги: `--camera` - часть имени камеры (по умолчанию `iPhone`), `--hfov` - угол обзора камеры.
Клавиши в окне: `q` - выход, `r` - заново выбрать лектора.

## Железо

- Arduino Nano, серва MG996R, голова штатива поворачивается через четырёхзвенник
- серва питается отдельно: 12 В -> понижающий модуль XL4015, выставленный на 6 В
- красный провод сервы - OUT+ модуля, коричневый - OUT- модуля и GND Arduino (земля общая)
- жёлтый - D9 через резистор 550 Ом
- Arduino питается от USB Мака

Крайние положения зависят от тяги, подбираются под конкретную конструкцию: залить `firmware/servo_calibrate` на плату,
в Serial Monitor (115200, "New Line") командами `+` / `-` / `number` найти левый и правый край
и прямое положение. Эти числа вписать в `MIN_US`, `MAX_US`, `CENTER_US` в
`firmware/tripod_servo` и залить его. Если камера крутится не в ту сторону, поменять `servo_dir`
в `tripod/config.py`.

## Как устроено

- `tripod/camera.py` - захват с iPhone через AVFoundation, берётся только свежий кадр
- `tripod/detector.py` - YOLO11n на MPS, только класс person
- `tripod/tracker.py` - держит одного человека, головы слушателей внизу кадра игнорируются
- `tripod/controller.py` - зоны в градусах, alpha-beta фильтр и прогноз: поворот, если лектор
  у края кадра или уверенно идёт к нему
- `tripod/link.py` - протокол с Arduino: `T <мкс>` и `S` туда, `READY`, `A <мкс>` и `L` обратно
- `firmware/tripod_servo` - разгон и торможение сервы, лимиты хода, остановка без команд
- `firmware/servo_calibrate` - ручной подбор крайних положений
